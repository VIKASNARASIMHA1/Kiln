# Supervised learning

In supervised learning a model learns from examples that have inputs, called features, and known answers, called labels. Regression predicts a number, such as a house price. Classification predicts a category, such as spam or not spam.

Linear regression fits a line through the data by minimising squared error. Logistic regression outputs a probability for a class. Decision trees split the data on feature thresholds, and random forests average many trees to be more stable.

Always split data into training and test sets so you measure performance on examples the model has not seen.
